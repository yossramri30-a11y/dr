# Droits Design TN

Site statique en français sur les droits essentiels d'un designer en Tunisie.

## Fichiers

- `index.html` : structure de la page
- `styles.css` : direction visuelle
- `script.js` : contenu, filtres et recherche

## Sujet couvert

- droit d'auteur
- cession de droits et contrats
- OTDAV
- INNORPI
- CNSS
- recours en cas de litige

## Note

Le contenu est conçu comme un guide pratique fondé sur des sources officielles ou juridiques consultées le 21 mai 2026. Ce n'est pas un avis juridique personnalisé.
